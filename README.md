# HomeBro — бот поиска квартир в Кишинёве

Telegram-бот @homebro_chisinau_bot: поиск квартир в аренду, объявления от владельцев
с модерацией, избранное и подписки на новые квартиры. Интерфейс на RU / RO / EN.

*In English:* a Telegram bot for apartment rentals in Chisinau. Search with filters, an 18-step listing form for owners, admin moderation, favorites and saved-search alerts, three languages. Python, aiogram 3, SQLite.

## Установка на новый компьютер (Windows)

1. Установите **Python 3.12 или новее** с https://www.python.org/downloads/
   При установке отметьте галочку **«Add python.exe to PATH»**.
2. Распакуйте архив в любую папку (лучше без кириллицы в пути, например `D:\homebro-bot`).
3. Запустите **`install.bat`** двойным кликом. Он создаст окружение, поставит библиотеки
   и откроет файл `.env` в Блокноте:
   - `BOT_TOKEN=` — токен бота от @BotFather;
   - `ADMIN_IDS=` — Telegram ID админов через запятую (свой ID можно узнать у @userinfobot).

   Если архив собран **с данными**, `.env` и база уже внутри — ничего вписывать не нужно.
4. Запустите **`start.bat`** — откроется окно с логами, бот работает, пока окно открыто.

> ⚠️ Бот должен работать **только на одном компьютере одновременно**.
> Перед запуском на новом ПК остановите его на старом, иначе Telegram выдаст ошибку `Conflict`.

## Файлы

| Файл | Что делает |
|---|---|
| `start.bat` | Запускает бота и показывает логи. Если бот упал — перезапускает через 10 секунд |
| `install.bat` | Первая установка: окружение, библиотеки, файл `.env` |
| `package.bat` | Собирает архив в папке `dist`: только код или код + данные |
| `.env` | Токен и ID админов. **Никому не передавайте** |
| `bot.db` | База: пользователи, объявления, подписки. **Делайте резервные копии** |
| `logs/bot.log` | Журнал работы бота (хранятся последние ~5 МБ) |

## Перенос бота на другой ПК

1. На старом ПК: `package.bat` → вариант **2 (код + данные)**.
2. Остановите бота на старом ПК (закройте окно `start.bat`).
3. Перенесите архив из папки `dist`, распакуйте, запустите `install.bat`, затем `start.bat`.

Фото квартир хранятся на серверах Telegram, в базе только ссылки на них — переносить их не нужно.

## Резервная копия

Тот же `package.bat` → вариант 2. Храните архив в надёжном месте (не в общем доступе):
в нём токен бота и телефоны пользователей.
